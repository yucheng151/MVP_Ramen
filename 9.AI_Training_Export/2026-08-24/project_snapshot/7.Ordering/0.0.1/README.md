# 手機點餐前台 0.0.1

這一版只處理顧客手機點餐，不包含 HMI、PLC、麵格選擇或庫存判斷。

## 目前功能

- 一項測試餐點：經典豚骨拉麵，NT$180
- 選擇麵條硬度
- 確認訂單
- 同一張訂單可選擇多碗
- 顯示取餐號碼與「等待製作」狀態
- 尚未連接 HMI 時，以瀏覽器本機資料模擬下單

## 開啟方式

直接用瀏覽器開啟 `index.html` 即可操作。手機測試時，可使用任一靜態網站伺服器分享此資料夾。

公開版本由 Sites 提供 HTTPS 網址，任何能連上網路的手機都可以直接開啟，不需要 LINE 或安裝 App。

## 下一階段串接

HMI 後台提供訂單 API 後，在頁面載入 `app.js` 前設定：

```html
<script>window.ORDER_API_URL = 'http://HMI電腦位址/api/orders';</script>
```

送出的訂單包含顧客選擇的 `quantity`，但不包含麵格編號。HMI 後台應將多碗訂單拆成單碗製作任務，每次只向 PLC 下達一碗的指令；麵格選擇也由 HMI 後台處理。
